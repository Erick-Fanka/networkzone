## 1. Inicialização e Monitoramento do Switch

Antes mesmo de começarmos a configuração, o switch passa por 5 etapas de inicialização:

1. **POST (Power-on Self-Test):** Armazenado na ROM, testa a CPU, a DRAM e a memória flash.
2. **Boot Loader:** Um programa pequeno na ROM, executado imediatamente após o POST.
3. **Inicialização da CPU:** O *boot loader* mapeia a memória física, a quantidade e sua velocidade.
4. **Sistema de Arquivos:** O *boot loader* inicializa a memória flash na placa principal.
5. **Carregamento do IOS:** Localiza a imagem padrão do sistema operacional e passa o controle ao IOS.

A variável de ambiente `BOOT` armazena o caminho do arquivo `.bin` (a imagem IOS). Caso ela não tenha sido configurada ou não exista, o switch entra em modo de sobrevivência e busca o primeiro executável. Exemplo do comando:

```bash
boot system flash:/c2960-lanbasek9-mz.150-2.SE/c2960-lanbasek9-mz.150-2.SE.bin
```

Podemos usar os LEDs frontais para monitorar rapidamente o desempenho. Segue a finalidade de cada um:

| Indicador LED | Significado dos Status |
| :--- | :--- |
| **SYST (Sistema)** | Verde: normal. Âmbar: recebendo energia, mas com falha. Apagado: desligado. |
| **RPS (Fonte Redundante)** | Verde: pronto. Piscando (Verde): em uso por outro dispositivo. Âmbar/Piscando: falha na fonte interna ou em espera. |
| **Status (Porta)** | Verde: link presente. Piscando (Verde): atividade de dados. Âmbar: bloqueado por STP (evitar loop). Alternando: falha. |
| **DUPLX (Duplex)** | Indica que o modo duplex da porta está selecionado. |
| **SPEED (Velocidade)** | Apagado: 10 Mbps. Verde: 100 Mbps. Piscando (Verde): 1000 Mbps. |
| **PoE (Energia)** | Verde: PoE ativo. Piscando ou Âmbar: falha ou negado por limite de capacidade do switch. |

## 2. Recuperação de Travamento de Sistema

O *boot loader* fornece acesso ao switch se o IOS estiver danificado ou ausente. Podemos acessá-lo usando um cabo console com os seguintes passos:

1. Conecte um PC à porta console do switch via emulador de terminal.
2. Desconecte o cabo de alimentação do switch.
3. Reconecte o cabo e, em até 15 segundos, mantenha pressionado o botão **MODE** (enquanto o LED do sistema pisca em verde).
4. Continue pressionando até o LED ficar brevemente âmbar e depois verde sólido; solte o botão.
5. O prompt `switch:` aparecerá no terminal. 

> ** Dica:** Digite `help` ou `?` para listar os comandos.

Comandos úteis para alterar a variável e inicializar o switch:

```bash
switch: set  # Exibe o caminho atual da variável BOOT
switch: flash_init  # Inicializa o sistema de arquivos flash
switch: dir flash:  # Exibe diretórios e arquivos (ex: seu arquivo .bin)
switch: BOOT=flash:c2960-lanbasek9-mz.150-2.SE8.bin  # Altera a variável BOOT
switch: boot  # Reinicia o equipamento
```

## 3. Gerenciamento Remoto e SVI

Para gerenciar um switch remotamente, ele deve ser configurado com IP, máscara e gateway padrão. Utilizamos a **SVI (Switch Virtual Interface)**, responsável pelo gerenciamento remoto e roteamento inter-VLAN (em L3). 

Por padrão, o gerenciamento usa a VLAN 1. Por motivos de segurança, a melhor prática é utilizar uma VLAN dedicada (ex: VLAN 99).

```text
! Passo 1: Configurar a interface de gerenciamento
Switch# configure terminal
Switch(config)# interface vlan 99
Switch(config-if)# ip address 172.12.99.11 255.255.255.0
Switch(config-if)# ipv6 address 2001:db8:acad:99::1/64
Switch(config-if)# no shutdown
Switch(config-if)# exit

! Passo 2: Configurar o gateway padrão
Switch(config)# ip default-gateway 172.17.99.1
Switch(config)# end

! Passo 3: Salvar e verificar
Switch# copy running-config startup-config
Switch# show ip interface brief
```
